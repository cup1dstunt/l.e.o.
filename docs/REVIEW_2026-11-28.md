# Code-Review 28.11.2026

Gezieltes Review von `main` (Stand nach PR #44) mit Blick auf PR #46. Schwerpunkt: Datenverlust, Speicherung und Abgleich, doppelte Kennungen, WebUntis/IServ, Import. Die Notenberechnung wurde nicht erneut geprüft, weil der Rechenkern in PR #44 gerade umgebaut wurde.

Alle 23 Prüfdateien (`npm test`) und `npm run check` laufen grün. Gegen echtes WebUntis und auf echten Geräten ist nichts davon getestet.

## Geprüft, ohne Befund

- Speichern je Datensatz, Löschen und Wiederherstellen (Stände, Sicherungsdatei, Einspielen lädt die Seite neu).
